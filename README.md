# Portafolio de Nátaly Cárdenas

Adaptación directa del código de https://github.com/programaconale/DATACONALEWEBSITE (commit 47679e351890a5f37bf4d118dcd8969fdcc8f90d), con los componentes, tipografías y animaciones originales. Perfil, experiencia, enlaces y paleta personalizados para Nátaly.

## Desarrollo

`npm ci` y `npm run dev`. Perfil y contenido en `src/lib/data.ts`. No se publica ningún PDF. Las imágenes y el vídeo personales del autor original se sustituyeron por las iniciales NC; no se dispone de fotografía o vídeo de Nátaly.

## GitHub Pages

Cada push a `main` compila Next.js como sitio estático y publica `out` mediante GitHub Actions. La ruta base es `/Portafolio_Web`.

Paleta: Lagoon #95DFD3, Deep Sea #1F4B5D y blanco #FAFAFA. Tipografías locales: Inter Tight, Instrument Serif y JetBrains Mono (SIL Open Font License). Créditos y licencias de los iconos conservados en `public/logos`.
